# Triage 标签映射

各技能按五个固定 triage 角色说话，本文件把角色映射到本仓库 tracker 里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给无人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当技能提到某个角色（如"打上 AFK-ready 标签"）时，使用本表右列对应的标签字符串。

要适配自己的叫法，只需改右列。
